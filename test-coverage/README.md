# Test Coverage Report

This directory contains the JaCoCo HTML test coverage report generated by Maven.

## How to Generate

```bash
cd petreminder-app
mvn clean test
```

The report is generated at:
- `petreminder-app/target/site/jacoco/index.html` (JaCoCo HTML)
- `petreminder-app/target/site/coveragereport/` (ReportGenerator HTML)

> The JaCoCo HTML report is generated during CI and attached as a build artifact.
> A copy of the latest report is stored here for offline review.
